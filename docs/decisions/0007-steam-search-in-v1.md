# 0007 · Steam 검색 등록과 커버 이미지를 v1.0에 넣는다

- **상태**: 채택
- **날짜**: 2026-11-03

## 맥락

M2.5를 v1.0(M2 다음)에 넣을지 v1.1(M4 다음)로 뺄지 미뤄 두었고, S-03 등록 폼이 이 결정을 기다리고 있었다. 비교표에는 v1.1로 빼자는 제안이 있었다.

## 결정

v1.0에 넣는다. S-03은 처음부터 Steam 검색 자동완성으로 만든다. 사용자가 비교표를 보고 정했다.

## 검토한 대안

- **v1.1로 빼기** — 남은 v1.0이 S-03 → M3 → M4로 짧아지고, 나중에 제목 칸만 고치면 된다. 대신 v1.0은 커버 없이 회색 두 글자로 나간다.

## 감수할 것

- v1.0까지 1 ~ 2주 늘어난다. 출근 후 짧은 세션으로 서버 작업을 하다가 v1.0 전에 멈출 위험이 커진다.
- 그래서 직접 입력 경로를 항상 유지한다. M2.5가 중간에 멈춰도 등록 자체는 막히지 않는다.
