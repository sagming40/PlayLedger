# 0014 · M8 Steam 동기화와 M11 Discord 로그인을 M6 · M7보다 먼저 한다

- **상태**: 대체됨 → [0017](0017-milestone-renumber.md)
- **날짜**: 2026-11-06

## 맥락

M5(배포)를 닫고 12월 서버 이사(M5.5)까지 시간이 있다. 이사를 12월로 둔 것은 Vultr 크레딧(11-30 만료)을 다 쓰려는 것이고, 앞 단계가 끝나야 하는 관계는 아니다. 사용자가 Steam · Discord 연동을 먼저 해 보고 싶어 했다. `PLAN` 4장에서 M8 · M11 앞의 화살표는 점선(권장 순서)이라 막는 의존 관계는 없다.

## 결정

M8 → M11 → M6 → M7 순서로 한다. M9(자동 동기화) · M10(플레이 세션)은 원래 자리에 둔다. 단계 번호와 버전(v2.0 · v2.1)은 바꾸지 않고, 그 버전에 들어갈 기능이 다 모였을 때 태그를 붙인다. M5.5 이사는 12월에 그대로 한다.

## 검토한 대안

- **원래 순서(M6 → M7 → M8)** — 이사까지 남은 3주에 M6 · M7을 하는 것도 된다. 사용자가 해 보고 싶은 것을 미루면 학습 프로젝트의 동력이 떨어진다
- **단계 번호를 다시 매기기** — 문서 곳곳의 `M8` · `M11`을 바꿔야 하고 옛 기록과 어긋난다

## 감수할 것

- v1.1(F-14 추첨) · v1.2 태그가 v2.0 기능보다 늦게 붙는다. 버전 번호가 출시 순서를 뜻하지 않게 된다
- M8을 하는 동안 M10(세션)이 없다. 동기화의 "증가분을 세션으로" 부분은 M10에서 붙인다 (`ARCHITECTURE` 5.1절)
- M11의 계정 연결 정책(R-07)을 M11 시작 때 정해야 한다
