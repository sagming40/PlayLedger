  - 동시 실행: DELETE 2건 → 204 · 204. PATCH + DELETE 20회 → PATCH 200 또는 404, DELETE 모두 204, 서버 500 · `StaleDataError` 0건 (고치기 전 6회 중 3회 500)

### [설계]
- **`AlertDialogAction`을 쓰지 않는다**: 누르는 순간 닫혀서 실패를 그 자리에서 보여 줄 수 없다. 답이 올 때까지 열어 둔다
- **지운 뒤 돌아가기**: 목록에서 왔으면 `router.back()` ─ 필터가 남는다. 방문 기록 앞쪽에 지운 기록이 남아 앞으로 가기를 누르면 "찾을 수 없어요"가 나온다. 감수
- **삭제 후 알림은 아직 없다**: 저장 알림 작업에서 같이 본다
- **⋮ 메뉴는 `modal` 끔**: 메뉴가 닫히면서 곧바로 대화상자가 열린다. 둘 다 화면을 잠그면 잠금 해제가 부딪칠 수 있다

### 막힌 것
- 증상: 화면 흐름에서 PATCH + DELETE를 동시에 보내자 6회 중 3회 500. 두 기기에서 한쪽은 수정, 한쪽은 삭제하는 상황 (사전 검증에서 예상하고 일부러 돌림)
  - 원인: 서버 로그 `StaleDataError: UPDATE ... expected to update 1 row(s); 0 were matched`. 수정이 행을 읽은 뒤 삭제가 끝났다
  - 해결: 수정 API가 `SELECT ... FOR UPDATE`로 읽는다. 잠금이 풀린 직후 지워질 수 있어 재조회가 비면 404
- 증상: 그 잠금을 지키려고 쓴 pytest가 **잠금을 빼도 통과했다**. 두 번 고쳐 썼다
  - 처음엔 이걸 "잠금이 필요 없다"로 잘못 읽고 잠금을 뺐고, 고치기 전 코드에서도 통과하는 걸 보고서야 테스트가 틀렸다는 걸 알았다. 서버 로그를 보고 원인을 다시 확정했다
  - 원인: `await asyncio.sleep(0.3)` 뒤 "아직 안 끝났다"로 대기를 판정했는데, 이 환경은 새 DB 연결이 약 2초 걸려서 잠금과 상관없이 항상 안 끝나 있었다
  - 해결: 수정이 읽은 직후 삭제를 끼워 넣고, `pg_stat_activity`에서 DELETE가 잠금을 기다리는지 DB에 직접 묻는다. 잠금을 빼면 "삭제가 기다리지 않고 끝났다"로 실패하는 것을 확인
  - 배운 것: **동시 실행 테스트는 고치기 전 코드에서 실패하는 것부터 본다.** 대기는 시간이 아니라 DB에 물어서 판정한다. 원인은 추측하지 말고 로그부터 본다
- 증상: 첫 흐름 실행에서 목록 카드를 못 찾아 멈춤
  - 원인: 확인 스크립트. `reka-ui` 새 import로 Vite가 다시 묶는 중이라 고정 1.5초로는 목록이 안 떠 있었다. 내용이 생길 때까지 기다리게 고쳤다

- **시간당 비용을 M3에서 응답에 넣음**: `DESIGN` 3.4절이 "서버 계산값"이라 S-04가 기다릴 수 없었다. 건별 값만 계산 필드로 넣고(저장 안 함 ─ 플레이타임을 고치면 바로 다시 계산), 통계 집계는 M4에 남겼다
  - 반올림은 정수로만 계산하는 0.5 올림. `round()`는 0.5를 짝수로 보내서 1원 · 2시간이 0원이 된다(테스트 `(1, 120, 1)`)
  - 구매가를 안 적어도 `—`. `REQUIREMENTS` 5.1절은 플레이타임 0만 적었지만 나눌 값이 없기는 같다
- **상태는 기본 select**: 목업대로. 모바일에서 OS 선택창이 뜨고 키보드 · 화면 읽기가 그대로 된다
- **고르자마자 반영 + 저장 중 잠금**: 점 색 · 평가 카드가 바로 바뀌어야 "바뀌었나?"를 안 묻는다. 대신 두 요청이 거꾸로 도착하지 않게 저장 중에는 잠근다. 실패하면 되돌린다
- **상세 → 상세 이동은 번호표**: 화면이 다시 만들어지지 않고 id만 바뀌어서, 늦게 온 앞 게임 답이 덮어쓸 수 있다. `useSteamSearch`와 같은 방법
- **평가 카드는 값이 있을 때만**: CLEARED인데 평점이 없으면 빈 카드가 된다. 입력은 다음 작업(평점 입력)에서 수정 화면에 붙는다
- **수정 버튼 · ⋮는 아직 안 그림**: 누를 곳 없는 버튼은 고장으로 보인다. 수정 · 삭제 작업에서 같이 붙인다
- 배경 커버는 48rem부터 흐리게(`blur-md`). Steam 커버가 460px 폭이라 넓은 화면에 늘리면 거칠다. 또렷한 커버는 카드가 맡는다
