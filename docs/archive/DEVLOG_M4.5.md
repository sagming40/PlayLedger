### [설계]
- 요청 제한은 새 패키지 없이 프로세스 메모리에 둔다. 서버 한 대 · 워커 하나가 전제다(M5에 명시)
- 재발급은 서버 유예 시간 없이 `navigator.locks`로만 푼다. 앞 탭이 끝난 뒤 보내면 브라우저가 새 쿠키를 싣는다
- 개인정보 안내는 법적 고지문이 아니라 실제로 무엇이 어디로 가는지 적는다. 법률 검토는 받지 않았다
- 배포 후로 미룸: 이메일 인증, 가입 이메일 존재 노출 완화, 흔한 비밀번호 차단, 모션 라이브러리 축소, 복귀 스크롤 위치, 글꼴 내장(M5)

### 막힌 것
- **마이그레이션이 공유 데이터에서 실패.** 증상: 3명이 공유한 게임을 복제할 때 `uq_games_title_norm_manual` 위반. 원인: 옛 UNIQUE를 복제 뒤에 지웠다. 테스트 DB는 비어 있어 pytest로는 안 잡힌다. 해결: 인덱스를 먼저 삭제. 배운 것: 데이터 마이그레이션은 데이터를 넣고 왕복 돌려 본다. 결과: 공유 게임 → 3행, 장르 복제, `updated_at` 유지, downgrade로 다시 합쳐짐
- **잠금 테스트가 잠금 없이도 통과.** `gather`로 삭제와 등록을 15번 겹친 테스트가 `FOR UPDATE`를 지워도 통과했다. 순서를 고정한 테스트로 바꾸고 잠금을 지우면 실패하는 것을 확인했다
- **시험 뒤 되돌리기를 `git checkout`으로 해서 미커밋 변경을 날렸다.** `services/game.py`를 패치 스크립트로 다시 적용했다. 이후로는 파일 복사로 되돌린다
- **새 테스트가 멈춤.** `last_appid`가 이상하면 미러링이 끝없이 돌았다. 진짜 구멍이었다. 멈춘 탓에 그 묶음의 고치기 전 실패 건수는 세지 못했다
- **이탈 확인이 두 번 뜨고 취소해도 나감.** `RouterLink`에 `@click.prevent`를 달면 자기 이동과 내 함수가 둘 다 돈다. 원래 있던 이중 이동이 이탈 확인을 붙이며 드러났다. `custom`으로 해결
- **오프라인에서 화면 조각 실패 → 새로고침 → 브라우저 오류 페이지.** `navigator.onLine`이 거짓이면 새로고침하지 않고 띠로 안내
- **CI audit 첫 실행 실패.** PyJWT · certifi · dnspython 알려진 취약점 5건. 버전을 올려 0건
- 개인정보 안내를 쓴 뒤 Google Fonts로 접속 IP가 나가는 것을 빠뜨린 것을 발견해 추가
