# 0009 · 수동 게임과 Steam 게임은 합치지 않고 별개 행으로 둔다

- **상태**: 채택
- **날짜**: 2026-11-03

## 맥락

같은 `title_norm`의 수동 게임이 있을 때 Steam 게임을 등록하면, 그 행에 appid를 붙일지 새 행을 만들지 정해야 했다. M8 동기화에도 같은 문제가 있다.

## 결정

별개 행으로 둔다. 판별은 `DATA_MODEL` 2.4절 그대로다: appid가 있으면 appid로만 찾고, 없으면 수동 게임 중에서만 찾는다. 병합은 나중에 관리자 화면(F-23)에서 사람이 한다.

## 검토한 대안

- **제목이 같으면 수동 행에 appid를 붙인다** — 리메이크처럼 제목만 같은 다른 게임이 합쳐지면 공유 테이블을 쓰는 모든 사용자의 기록이 엉뚱한 게임을 가리킨다. 중복 행은 나중에 합칠 수 있지만 잘못 합친 것은 되돌리기 어렵다 (2026-09-21 정규화 규칙과 같은 판단).
- **사용자에게 그때 묻는다** — 등록 흐름이 길어지고, 공유 데이터를 한 사람의 판단으로 바꾸는 것은 그대로다.

## 감수할 것

- 같은 게임이 수동 · Steam 두 행으로 남을 수 있고, 한 사용자가 양쪽을 다 등록하면 통계에 두 번 들어간다.
