# 0010 · 데스크톱 메뉴를 왼쪽 사이드바에서 상단 메뉴 띠로 바꾼다

- **상태**: 채택
- **날짜**: 2026-11-03

## 맥락

48rem 이상의 메뉴는 폭 240px의 왼쪽 사이드바였다. 사용자가 투박하고 안 예쁘다고 봤고, material-dict의 상단 알약 메뉴를 참고로 가져왔다.

메뉴 3개가 높이 약 140px만 쓰는데 세로 기둥은 화면 끝까지 이어져 아래가 비어 있었다. S-02의 포스터 벽도 사이드바에서 끊겼다.

## 결정

- 48rem 이상은 위쪽 메뉴 띠를 쓴다. 불투명 배경 + 아래 구분선, 포스터 벽은 그 아래에서 시작한다 (시안 H, `mockups/TopNav.dc.html`).
- 메뉴는 알약 묶음에 아이콘 + 글자로 넣고, 활성 메뉴는 포인트 색으로 채운다. `DESIGN` 4.4절의 "꽉 채우지 않는다"에 활성 메뉴를 예외로 둔다.
- 활성 메뉴와 빨강이 겹치지 않도록 선택된 필터 칩을 무채색으로 바꾼다.
- `+ 게임 등록`을 띠 오른쪽 끝으로 옮긴다. 라이브러리 밖에서도 누를 수 있다. S-03에서는 숨긴다.
- 48rem 미만의 하단 탭은 그대로 둔다. 자주 누르는 기록 앱이라 엄지가 닿는 아래가 맞다. 띠가 없으므로 등록 버튼은 화면 안에 남긴다.
- 띠와 본문은 최대 1280px 가운데 정렬이고, 포스터 벽만 화면 끝까지 깐다.

## 검토한 대안

비교 그림은 `mockups/TopNavBoard.dc.html`에 모두 남겼다.

- **A 벽 위의 유리 알약 · C 벽 위의 글자 탭** — 벽이 끊기지 않지만 사용자는 B 계열을 더 마음에 들어 했다.
- **B material-dict 그대로** — 활성 메뉴 · `전체` 칩 · `게임 등록`까지 빨강이 세 군데였다. 칩을 무채색으로 바꾼 것이 D다.
- **D 칩만 무채색** — 띠 오른쪽이 비어 허전하다.
- **E 띠에 게임 등록** — 채택안의 바탕이다. 여기에 G의 아이콘을 더한 것이 H다.
- **F 떠 있는 캡슐** — 띠 대신 벽 위에 둥근 캡슐을 띄운다. 벽이 끊기지 않아 사용자도 마음에 들어 했다. **버리지 않고 나중에 다시 볼 후보로 둔다.** 벽의 글자가 제목 뒤로 비치는 것은 그때 풀어야 한다.
- **G 가운데 아이콘 알약** — 아이콘만 가져왔다. 가운데 정렬은 로고와 빈 오른쪽의 무게가 맞지 않았다.

## 감수할 것

- 띠 안에 빨강이 둘이다(활성 메뉴 · 등록 버튼). 왼쪽과 오른쪽으로 떨어져 있어 받아들였다.
- 라이브러리 제목 줄의 등록 버튼이 데스크톱에서 사라진다.
- 포스터 벽이 띠 아래에서 시작해 화면 맨 위까지 올라가지 않는다.
- 기존 데스크톱 목업의 사이드바는 다시 그리지 않고 옛 안으로 표시만 한다.
