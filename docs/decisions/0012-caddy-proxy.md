# 0012 · 프록시는 Nginx 대신 Caddy를 쓴다

- **상태**: 채택
- **날짜**: 2026-11-04

## 맥락

처음 문서는 운영 프록시를 Nginx로 적었다. 실제 배포 경험은 그 뒤에 생겼다. cbt-journal이 `sagming.com` 하위 주소를 Caddy + Let's Encrypt로 운영 중이고, 서버 세팅 명령과 설정 파일이 그 저장소 `deploy/`에 있다.

## 결정

Caddy를 쓴다. 화면 정적 파일을 내주고 `/api`를 FastAPI로 넘기며 HTTPS 인증서를 스스로 받고 갱신한다.

## 검토한 대안

- **Nginx** — 예전 문서대로. 인증서를 받고 갱신하는 도구와 타이머를 따로 둬야 하고, 이미 익힌 설정을 쓸 수 없다

## 감수할 것

- Nginx 설정 경험은 쌓이지 않는다
- 프록시 뒤에서는 요청 제한이 프록시 IP 하나로 묶이지 않게 uvicorn에 `--proxy-headers`와 믿을 프록시 주소를 줘야 한다 (`PLAN` M5)
